# 阶段三、四实现说明（文字版）

## 1. 与 MATLAB 原型的对应

`code/stage3_4_thz.py` 是把 `阶段一二复现/matlab` 里的三份脚本合并、换成太赫兹信道后的版本：

| MATLAB | 本仓库 |
| --- | --- |
| `simulate_stage3.m`（ns=8 互斥时分） | `run(..., mode="static")` |
| `ekf_bidirectional_step.m`（式 27-31） | `Terminal.passive_step` |
| `stage_config.m` 式(25)(26) | `RadiusLaw` |
| `simulate_stage4_dynamic.m` | `run(..., mode="dynamic")` |

差别只有三处：信道换成实测方向图 + P.676，状态从 3 维扩到 6 维，角度量纲按半功率宽度重标
（`s = 0.7677°/35.3° = 0.0217`）。

## 2. 时分调度

```
slot      = k mod (2·ns)
active    = 0 if slot < ns else 1
sample    = slot mod ns
psi       = sample · 45°
age       = (ns − 1 − sample) · dt / ns
```

被动端的半径与增益在同一拍门控为零，只保留一个 0 偏置功率样本。每块 8 拍，两端交替，任一时刻有且只有一端 Active。

## 3. 被动期的标量退化

主动期的全维更新是 `P⁻ = ΦPΦᵀ + Q`、`K = P⁻Cᵀ(CP⁻Cᵀ+R)⁻¹`、Joseph 形式。
被动期不做这件事，改成：

```
q        ← q                                  # 不拿 q_dot 外推
P11      ← P11 + 1e-8
K1       = P11 / (P11 + R_eff)
q        ← q + K1·(z − q − g(ê))
P00      ← (1−K1)·P00
P0j,Pj0  ← (1−K1)·P0j
```

四个角度状态与 `P_ang` 的 4×4 块逐位不动，实测偏差为 0（门限 1e-12）。
`R_eff` 里额外加了 `ΔL(±1σ)²`：被动期没有角度观测，指向不确定度会以损耗的形式混进功率样本，
不加这一项就会把损耗长期记到 q 头上。

## 4. 变半径

```
r = clip(2.2 · sqrt(max eig(P_ang)), 0.0435°, 0.0844°)
```

作者的形式是 `r = K_delta·Σλ_max`，`K_delta = 1/(7000·ns)`。他的 `P_ang` 被 `Q_scaling=1e5` 放大过，
特征值在 1e4 deg² 量级；本滤波器用真实 deg²，直接乘会恒等于零，所以保留窗口求和的结构、
把尺度换成角度标准差。上下限按 HPBW 重标：2°–5° × 0.0217，再按 0.11 HPBW 封顶。

## 5. 正交运动

```
每步位移 = 0.005·v/√2 m
Rover   : p_y += d
Elevator: p_z += d
```

v = 0.2 时每步 0.707 mm，100 秒距离 2.3000 → 2.3087 m，与作者 Fig.9 构型一致。
视距角速度约 0.02°/s，一圈扫描 4 秒转 0.08°，约 0.1 HPBW。

## 7. 调参中踩到的坑

1. 被动期用 `q_dot` 外推 q，8 拍能把基线推走 1.2 dB，转主动后 V 轴反号。
2. 被动期 `R_eff` 用局部梯度估，峰顶梯度为零，q 被压死在偏差上，第二个上台的终端必发散。
3. 逐拍回中会把估计清零，q 吃掉角度信息；必须 8 点批量、块末回中。
4. 只缩 `P00` 不缩 `P0j` 会破坏半正定，`predict` 抛 PSD 异常；按 α 成对缩放。
5. 回中增益 1.0 只在批量估计下成立；单点更新时要降到 0.6。
